## Installation/Setup
1. Install Python 3 from https://www.python.org/
2. Install Visual Studio Code.
3. Install Git from https://git-scm.com/
4. Clone this repository:

   git clone https://github.com/narendra462/python.git

5. Open the project folder in Visual Studio Code.

## How to Run the Project
1. Open the terminal in Visual Studio Code.
2. Navigate to the folder containing the Python program.
3. Run the program using:

   python main.py

4. View the output in the terminal.

Note: Replace main.py with the actual filename of the program you want to execute.
